日N2 高频词训练系统产品设计说明书 v3.0供 Claude Code 执行 · 基于真实沟通整理核心理念：不是背了多少词，而是真正点亮了多少个开关。
衡量的是收获，不是付出。深度优于数量，少即是多。一、数据资产说明1.1 词库本质本词库来源于 2010-2025 年 28 份 JLPT N2 真题试卷，提炼出试卷上出现的全部有意义词汇。count 字段 = 该词在 28 份真题里出现的总次数（包括阅读文章、听力题、语法题目中的所有出现）。本质含义：想读懂 N2 试卷，必须认识的词。不是「N2词汇题考点」，而是「试卷阅读必备词汇」。1.2 四象限分类is_n2_core 字段来源：日语学习社区下载量最大的词表，由学习者用心整理，经过实战验证。象限数量定义优先级界面标注黄金词148个真题高频(count≥10) + 社区认可第一⭐ 黄金词隐藏考点1078个真题高频但社区未收录（可能是基础词被排除）第二📌 真题高频社区推荐1337个学习者实战整理，真实使用场景高频第三👥 社区推荐边缘词3444个两边均未收录，考前冲刺可跳过第四—1.3 架构原则（重要）数据和功能必须分离。代码只管流程，词从数据库读取。数据库里有多少词就处理多少词，加词只需插数据，不需要改代码。第一版填入148个黄金词，结构按6000词规模设计。二、核心设计哲学2.1 衡量标准的根本转变传统背单词本产品衡量标准今天背了多少词今天真正点亮了多少个开关首页核心数字已学词数：100今日点亮开关：7个学习目标看完词表把每个词真正打穿成就感来源数量多真正记住了2.2 每个词的5个独立状态开关5个开关相互独立，不要求按顺序点亮。哪个弱就攻哪个。5个全亮 = 这个词打穿了。开关字段含义点亮条件意思识别meaning_status看到这个词马上知道意思看到汉字能马上说出中文意思读音掌握reading_status看到这个词马上知道怎么读看到汉字能马上读出假名听音识别listening_status听到发音马上知道是哪个词听到音频能马上反应出意思用法掌握usage_status知道这个词怎么用、常见搭配能说出至少一个常见搭配自然输出output_status能在句子里自然用出来能造一个正确的简单句子2.3 手眼耳脑同时深度刺激原则感官必须同时参与，不能分开训练——分开训练感官之间没有记忆连接每个感官都有最低深度要求，不能一闪而过系统控制节奏，用户不能随意跳过每一步宁可今天只打穿3个词，也不要走马观花看50个词三、完整学习流程3.1 流程总览申报基础词汇量 → 筛词 → 预览词汇表 → 逐词深度学习 → 完成统计3.2 第一步：申报基础词汇量用户进入系统第一次使用时选择起点，系统直接信任，不单独做测试。选项对应词汇量说明完全零基础0词从第1个词开始学过五十音+基础约500词—N5水平约800词—N4水平约1500词—N3水平约3000词—自定义手动输入用户自己填数字筛词过程本身会自动校正真实水平：系统后台观察筛词结果，完成后呈现实际词汇量，不打断用户，不质疑申报。3.3 第二步：筛词从申报基础之上的词开始筛，用户判断每个词的掌握程度。筛词是最准确的诊断，样本几百个词，比任何测试都可信。按钮含义系统处理完全掌握5个开关都亮进入低频复查池看懂但不熟意思识别亮，其他弱进入弱词包只见过印象模糊进入生词包完全不认识5个开关全暗进入重点生词包，高优先级3.4 第三步：预览词汇表今日要学的词全部展示，用户快速扫一遍只显示汉字+中文意思，不需要记，让大脑先见一面（预览效应）用户自己点「准备好了，开始」才进入学习，不强制立刻开始3.5 第四步：逐词深度学习（核心）每个词按以下顺序完成，系统控制节奏，每步都有最低完成门槛，不能跳过。步骤感官系统行为完成门槛① 听音耳自动播放日语发音，慢速，带节奏间隔用户点「有感觉了」才继续② 眼耳同步眼+耳屏幕显示汉字+中文意思，同时循环播放发音用户自己感觉够了点「下一步」③ 联想故事脑显示联想故事，问「画面浮现了吗？」用户必须选「浮现了」或「没有」④ 跟读口显示假名分解，用户跟读后自己点「念完了」不做语音识别，自我确认制⑤ 例句眼+脑显示真题例句+播放例句音频自动进行，无需操作⑥ 延迟评分脑只显示假名，让用户主动回忆意思必须选一个评分才能继续3.6 音频播放设计细节阶段播放方式逻辑前5次（默认）慢速，带节奏间隔（播1秒停0.5秒）建立准确发音印象，不快速连播避免大脑屏蔽用户选「再来5次」正常速度印象建立后加速用户选「再来10次」快速洗脑模式被动强制输入，眼睛看字+耳朵听音同时进行用户选「够了」停止进入下一步洗脑模式设计：屏幕显示「漢字 + 中文意思」，耳机循环播放日语发音。眼睛负责意思，耳朵负责发音，两个通道各司其职不互相干扰。3.7
